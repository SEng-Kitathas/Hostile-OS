# C001 Semantic Helix ledger

Evidence inherits; confidence does not.

## Survivors

1. Execution identity, lineage, eligibility, and arbitration are independent relations.
2. Some tie/fallback consequence is required; storage position is only one carrier.
3. Linux graded service credit buys real wake-response/fairness behavior under contention, but P01 does not require that exact mechanism.
4. Counter magnitude is future-relevant; historical cause of the same current counter is not required as live arbitration state.
5. Priority/replenishment weight is future-distinguishable from current credit, but heterogeneous weight is extra capability relative to P01.
6. Continuation core requires instruction/stack/live-register/flags state plus execution-memory interpretation binding; substrate capabilities can add conditional context.
7. Continuation binding is required; embedding inside identity is not.
8. Resource access is independent from continuation.
9. Backing/resource identity is independent from per-access cursor/mode/applicability.
10. Shared read/write names are operation-family evidence, not proof of a universal File essence.
11. Wait condition, wake event, and resumed execution remain separate consequences.
12. Historical provenance/audit state remains separate from current operational state when future behavior is equivalent.

## Scars retained

- P05 first simulator re-arbitrated every tick and was invalid. It remains under `INVALID_*` plus `HARNESS_SCAR_001.md`.
- Earlier lab: QEMU `--version` succeeded while real machine creation failed because loadable accelerator modules were absent. Version smoke was not execution qualification.
- Earlier lab: a modern control root caused Linux child `ff00`; period-compatible userspace removed it. Fixture mismatch was not kernel failure.
- Earlier lab: old shell `sh SCRIPT` stalled while `. SCRIPT` worked. Invocation semantics were a fixture boundary, not an OS mechanism failure.
- Earlier lab: foreground tool windows killed/outlived long emulator/build operations. Durable detached launch + receipt ownership became mandatory.
- Earlier lab: modern GCC incompatibility was moved to external build adapters; canonical donor bytes remained 88/88 exact.
- FreeDOS toolchain absence was localized before BackDoor 004; no donor source edits were used to hide missing infrastructure.

## Rejected / narrowed

- `scheduler` as a primitive essence: not earned.
- task-table position as required tie invariant: rejected.
- explicit tie rank always better: rejected.
- one-bit wake credit as equal-capability replacement: rejected under high wake pressure.
- Linux half-decay as uniquely required: rejected; alternate bounded credit can approximate much of its behavior.
- priority as P01 minimum: rejected.
- full Linux `task_struct` as continuation essence: rejected.
- universal `File` object implied by common read/write API: rejected.
