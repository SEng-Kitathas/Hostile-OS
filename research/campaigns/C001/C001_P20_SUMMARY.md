## Minimum relation set earned so far

The evidence requires at least these future-relevant distinctions under the campaign scope:

- execution identity;
- lineage/parent-return relation;
- eligibility/currentness for execution;
- bounded arbitration with some tie/fallback consequence when multiple activities are eligible;
- CURRENT binding from selected activity to resumable continuation;
- continuation core: instruction position, stack position, live machine state, flags/condition state;
- execution-memory interpretation binding;
- wait condition, wake event, resumed execution as separate transitions;
- resource-access binding;
- backing/resource identity;
- per-access cursor;
- per-access mode/applicability/authority class (authority itself not yet fully qualified);
- persistent backing/history separate from current operational access state.

These relations can be physically bundled, but the campaign produced counterexamples against treating the bundles as indivisible essences.
