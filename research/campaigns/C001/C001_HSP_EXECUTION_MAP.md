## PDVER use

- **Probe:** source extractions, live donor fixture evidence, deterministic bounded models, counterexamples.
- **Derive:** future-relevance splits/merges, recurrence bound, capability vs requirement boundaries.
- **Verify:** exact-source checks, hand-trace validation, hash closure, cross-donor comparison, CSC replay of pass closure.
- **Recurse:** each next discriminator came from the predecessor result; P20 stops recursion for C001.

## Intelligent execution scars enforced

- foreground timeout != scientific failure;
- tool/version smoke != real execution qualification;
- fixture/harness defect != donor mechanism defect;
- source mirror != canonical bytes until byte comparison;
- build compatibility adapter != donor source mutation;
- green test != external truth;
- same ID/name != independent evidence;
- representation convenience != ontology;
- invalid P05 simulator retained and excluded instead of overwritten.
