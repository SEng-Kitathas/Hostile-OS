# HOSTILE-OS installable tree

This directory is reserved for the code, build logic, boot artifacts, and install/release surfaces that become part of an installable HOSTILE-OS.

Current state: **not yet installable**.

Research witnesses under `research/` are not silently promoted into this tree. A mechanism enters `os/` only after the project has earned and adopted it at the appropriate architecture/release gate.

Repository rule: a released build/install path must not require the `research/` tree to be checked out.
